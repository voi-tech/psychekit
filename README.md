# PsycheKit

Privacy-first, transparent engine for self-report questionnaires.

PsycheKit processes questionnaire responses locally in the browser. It has no accounts, backend, response analytics, or automatic AI integration. Completed results are stored only when the user explicitly opts in.

## Development

```bash
pnpm install
pnpm dev
pnpm verify
```
